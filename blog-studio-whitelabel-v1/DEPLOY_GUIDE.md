# 블로그 스튜디오 (화이트라벨) v1 — 운영자 가이드

고객 1곳 = Netlify 사이트 1개입니다. 같은 코드를 고객마다 따로 배포하고, 고객별 차이는 모두 앱의 **설정 탭**(관리자 전용)에서 정합니다. 코드를 고칠 필요가 없습니다.

## 폴더 구조
```
netlify.toml / package.json / package-lock.json
public/index.html
netlify/functions/api.mjs
netlify/functions/generate-background.mjs
netlify/lib/core.mjs
presets/example-preset.json      ← 설정 가져오기용 예시
CUSTOMER_INTAKE.md               ← 고객에게 받을 정보 양식
```

## 새 고객 추가 순서 (약 15분)
1. **GitHub**: 이 폴더를 그대로 올린 저장소를 하나 둡니다. 고객마다 저장소를 복사할 필요 없이, 저장소 1개를 여러 Netlify 사이트에 연결해도 됩니다 (코드를 고치면 모든 고객 사이트가 함께 업데이트됩니다).
2. **Netlify**: Add new project → Import an existing project → 위 저장소 선택 → 사이트 이름을 고객용으로 지정 (예: `moon-bakery-blog`).
3. **환경변수** (고객 사이트마다 따로 입력):

| 이름 | 값 |
| --- | --- |
| `ANTHROPIC_API_KEY` | Claude API 키 — 고객별로 키를 따로 만들면 비용이 고객별로 구분됩니다 |
| `TEAM_PASSWORD` | 고객 팀이 쓰는 비밀번호 (고객에게 전달) |
| `ADMIN_PASSWORD` | 운영자(나)만 아는 비밀번호 — 설정 탭이 열립니다 |
| `SESSION_SECRET` | 긴 무작위 문자열 (고객마다 다르게) |
| `CF_ACCOUNT_ID`, `CF_API_TOKEN` | (선택) AI 사진용 Cloudflare Workers AI |

4. Deploys → Trigger deploy. Netlify의 Visitor access(사이트 보호)는 꺼 둡니다.
5. 앱에 **관리자 비밀번호**로 로그인 → 설정:
   - **고객 프로필**: 앱 이름, 로고 글자, 포인트 색, 회사명, 업종, 주력 상품, 타깃 독자, 톤앤매너, 소재 축, 금지 사항, 필수 태그, 네이버 블로그 ID
   - **CTA**, **이미 다룬 주제**, **글쓰기 규칙**(공통 구조 규칙 — 대부분 그대로 사용)
   - **썸네일 배경·문구 형식**, **AI 사진 지침**
   - 연결 테스트 → 트렌드 글 1건 생성해 품질 확인
6. 고객에게 사이트 주소와 팀 비밀번호만 전달합니다.

비슷한 업종의 고객이 이미 있다면: 그 사이트에서 **전체 설정 내보내기** → 새 사이트에서 **설정 가져오기** → 프로필만 고치면 빠릅니다.

## 권한
- **팀 비밀번호 사용자(고객)**: 글 요청·검토·수정·사진·발행 처리. AI 공급사 이름과 비용은 보이지 않습니다.
- **관리자 비밀번호 사용자(운영자)**: 위 전부 + 설정 탭(프로필, 모델, 비용, 규칙).
- `ADMIN_PASSWORD`를 넣지 않으면 팀 비밀번호 사용자 전원이 관리자가 되므로 반드시 설정하세요.

## 고객 관리 팁
- 고객 목록을 표로 관리하세요: 고객명 / 사이트 주소 / 팀 비밀번호 / API 키 이름 / 개설일 / 월 비용.
- 비용은 각 사이트 설정 → API 비용(추정)에서 월별로 확인합니다. 정확한 청구액은 Anthropic Console의 키별 사용량을 보세요.
- 데이터(글·사진·히스토리)는 사이트마다 분리된 Netlify Blobs에 저장됩니다. 고객 간 데이터는 섞이지 않습니다.
- 백업: 설정 → CSV 내려받기(글), 전체 설정 내보내기(설정).
- 계약 종료: Netlify에서 해당 사이트를 삭제하면 데이터도 함께 삭제됩니다. 삭제 전 CSV를 고객에게 전달하세요.

## 지켜야 할 선
이 앱은 네이버에 자동 로그인·자동 발행하지 않습니다. 사람이 검토·승인한 글을 복사해 직접 발행하는 구조이며, 이 점이 네이버 이용약관을 지키는 핵심입니다. 고객에게도 그대로 안내하세요.
